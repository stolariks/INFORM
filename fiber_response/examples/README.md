# Platform usage examples

## Contents

This folder contains examples on how to programatically access the API and store the compute results


## Instalation

To use the examples here, package group `example` must be installed:

```sh
uv sync --group example, <other_groups_you_desire>
```

## How to run?

After the dependencies have been installed, run the code with:
```sh
uv run python3 example/<example_script>.py
```

Enjoy :)
